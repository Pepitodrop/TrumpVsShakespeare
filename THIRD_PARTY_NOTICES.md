## Shakespeare Programming Language

The Shakespeare Programming Language was designed by Jon Åslund and Karl Wiberg. This project implements a limited interpreter from the publicly documented language model and writes its own original `.spl` programs.

Overview:

<https://en.wikipedia.org/wiki/Shakespeare_Programming_Language>
